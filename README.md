## 指标概述

**巴菲特指标**（又称证券化率）是巴菲特在《Fortune》杂志2001年文章中提出的估值指标：

```
证券化率 = 全市场股票总市值 / 国民生产总值(GDP)
```

| 区间 | 含义 |
|------|------|
| < 60% | 显著低估（历史级底部区域） |
| 60% ~ 75% | 低估区 |
| 75% ~ 90% | 合理区间 |
| 90% ~ 110% | 偏高 → 顶部预警（对标真实历史顶：2007≈132%、2015≈101%） |
| > 120% | 极端泡沫区 |

> ⚠️ 历史顶部阈值以**校正后**的真实市值口径为准：2007年6124点约132%、2015年5178点约101%（早期版本因未计入IPO扩容曾显示200~475%的虚高值，已修正）。A股上市公司盈利98%来自国内，分子分母同源，难以达到美股2021年217%的极端值。

### GDP外推规则（point-in-time）

严格按照数据**发布日**（当年1月17日发布上年全年，季后约17天发布季度数据）回溯当时可得的GDP：

1. 当年已发布季度GDP → **按去年同期占比外推**：`上年全年GDP × 今年前N季 / 上年同期前N季`
   （缺同期数据时退回均摊法：`(Q1+Q2+Q3)/3×4`、`(Q1+Q2)×2`、`Q1×4`）
2. 上年全年GDP（当年1月17日后）
3. 上年已发布季度外推
4. 更早年份全年GDP

> 去年同期占比外推的误差比均摊法小一个数量级：只拿到 Q1 时平均绝对误差 1.7%（均摊法 12.8%），拿到三季时 0.5%（均摊法 4.3%）。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行（计算今天，自动回填上次运行以来的缺失交易日，同步更新HTML）
python main.py

# 3. 指定日期
python main.py --date 2024-12-31

# 4. 补历史缺口：从指定日期起把 Excel 中缺失的交易日全部补上
python main.py --backfill-start 2026-08-01

# 5. 仅重新生成HTML（不调API、不改Excel）
python main.py --html-only
```

输出文件：`output/A股证券化率.xlsx` + `output/证券化率.html`

**自动回填**：每次运行都会检查 Excel 最后一行到今天之间的缺失交易日并全部补齐（不再只写当天）；用 `--backfill-start` 可把更早的历史缺口（如半月采样之间的空隙）也一次性补成每日数据。已存在的日期自动跳过，不会重复请求API。

周末/节假日运行不会产生虚假数据点：非交易日会被对齐到最近交易日，已有该日数据则直接跳过。

### 自动更新（GitHub Actions）

`.github/workflows/daily.yml` 已配置：**每个工作日 16:30（北京时间）**自动运行 `python main.py`，有新数据就提交并推送 `output/` 下的 Excel 与 HTML。

- 手动触发：仓库 Actions 页面 → 「每日更新证券化率」→ Run workflow
- 周末/节假日触发时没有新交易日，日志显示「本次无新数据」，不会产生提交
- 触发时间略晚于 16:30 属正常（GitHub 定时任务会排队）

> 定时工作流在仓库连续 60 天无活动时会被 GitHub 自动停用；本工作流每次有新数据都会提交，因此不会被停用。若长期无新数据，去 Actions 页面点一次 Run workflow 即可恢复。

## HTML 可视化

每次运行后自动同步生成 `output/证券化率.html`（ECharts 交互式图表，双页面，右上角切换）：

### 📈 图表页

- **可视范围选择器**：顶部卡片直接选择起止日期（修改即生效/点应用），快捷按钮（近1/3/5/10年、全部）；**两图缩放双向联动**（任一操作同步到另一页面）
- **拖拽缩放**：底部滑块拖拽选择时间范围（滚轮缩放已禁用）
- **动态趋势线**：虚线为当前可视范围内的线性回归趋势（红=证券化率、紫=总市值），范围变化自动重算
- **总市值叠加**：点击图例「总市值(万亿)」叠加显示市值曲线（右侧橙色坐标轴）
- **估值参考区（动态·对数正态）**：对可视范围内数据取对数求均值μ±1σ，映射回原尺度划分——底部参考区(绿)、合理区(蓝，约覆盖中间68%)、顶部参考区(红)，随所选时间范围动态计算（乘除对称，适应右偏分布）
- **牛熊信号区间**：点击图例「牛熊信号区间」显示/隐藏——X轴方向标出历史牛熊信号区段（绿=熊市底部信号区、红=牛市顶部信号区），基于全历史逐点5项信号打分（≥4/5触发）合并生成；图表页与分析页**各自独立**开关，默认隐藏
- **预测转折点**：◆橙色菱形=离当日最近的总市值转折（Zigzag检测），峰→「预测牛市顶点?」、谷→「预测熊市底部?」
- **牛熊标注**：红圆=牛市顶点、绿圆=熊市底部
- **范围统计**：顶部实时显示可视范围的最值

### 📊 分析页

- **状态卡**：当前证券化率、历史分位、常规顶部区、常规底部区
- **分析图表**：与图表页功能完全一致（缩放/趋势线/市值叠加/信号区间等），额外叠加预测**虚线**——常规顶部区边界(红虚线)、常规底部区边界(绿虚线)、极端顶参考(点线)；Y轴保证预测区关键线始终可见
- **🔔 牛熊信号检测**：以选定日期为基准（默认当前，可输入历史日期验证，选任意日期会自动吸附到最近一条有判断的记录，也可用 ◀ / ▶ 逐条翻查），10年/5年/3年三窗口检查——估值位置（绝对锚点62%/90%+窗口分位）、短周期惯性（3年斜率方向）、中周期衰竭（5年走平/涨速衰减），5项条件打分给出强/弱/无信号
  - 窗口分位与斜率均按**真实日期**加权/回归：历史段是半月采样、近期是逐日采样，单纯数点数会让最近的密集段被过度加权
  - 历史验证：2024-02底（2635点）5/5底部信号、2015-06顶（5178点）5/5顶部信号；2016-01熔断低点、2024-10脉冲顶正确排除
- **牛熊预测**（自动检测，不依赖人工标注）：
  - Zigzag算法扫描全部数据点，波动>15个百分点才确认转折，自动识别大周期峰谷
  - 常规顶部区 = 峰分布P30~P70分位；常规底部区 = 谷分布P30~P70分位（随数据滚动更新，不写死）
  - 极端参考线：峰最大值 132%（2007年泡沫）、谷最小值 20%（2005年998大底）
  - 时间外推：近12个月趋势斜率；回撤参考：峰→谷平均跌幅、熊市周期平均时长
- **预测逻辑说明**：完整解释Zigzag检测、分位区间、极端值处理、外推方法、局限
- **图形解读**：证券化率、区域、趋势线、标记的完整说明

| 2008-10-28 | 🐻 熊市底部 | 1664 | **33%** |
| 2009-08-04 | 🐂 牛市顶点 | 3478 | **76%** |

## 项目架构

```
a-stock-indicator/
├── main.py                    # 入口：自动发现指标、CLI
├── core/                      # 基础设施（共享）
│   ├── cache.py               # JSON缓存 + TTL过期
│   ├── data_fetcher.py        # HTTP请求（重试+退避+UA轮换+限流+熔断）
│   ├── trading_calendar.py    # 交易日历（上证指数K线推导，供回填使用）
│   ├── base_indicator.py      # 指标基类（继承即自动注册，自动回填缺口）
│   ├── excel_writer.py        # Excel追加/更新
│   └── html_reporter.py       # HTML可视化（双页面图表+牛熊信号检测）
├── indicators/                # 指标实现（自动发现）
│   └── buffett_indicator.py   # 证券化率
├── data_sources/              # 数据源（各指标共享）
│   ├── market_cap.py          # A股总市值（实时+历史锚点插值）
│   └── gdp.py                 # 中国GDP（point-in-time外推）
├── output/                    # 输出目录（已纳入版本控制）
│   ├── A股证券化率.xlsx       # 计算结果
│   └── 证券化率.html          # 可视化页面
├── .gitignore
└── requirements.txt
```

### 核心设计原则

- **自动发现**：放在 `indicators/` 目录下、继承 `BaseIndicator` 的类自动被发现
- **多级降级**：每个数据源有2~3层备用源，主源被封自动切换
- **请求限流**：按域名独立限流，腾讯0.3s、东财2.0s间隔
- **熔断保护**：连续2次连接失败后该域名熔断120秒
- **本地缓存**：GDP数据24h缓存，K线数据进程内缓存
- **幂等写入**：同一日期的数据重复运行只更新不重复
- **自动回填**：运行一次自动补齐上次运行至今天之间的缺失交易日（基于腾讯K线推导的交易日历，周末/节假日自动跳过）
- **历史市值锚点校正**：16个真实市值锚点（交易所统计）+ 沪深双指数合成插值，校正IPO扩容高估
- **GDP point-in-time**：按发布日回溯，历史日期只用当时可得的GDP

## 数据源 & 反封策略

### A股总市值

| 优先级 | 源 | 协议 | 封IP风险 |
|--------|-----|------|---------|
| 1 | 腾讯财经 `qt.gtimg.cn` | HTTP | **不封IP** ✅ |
| 2 | 东财 push2 API | HTTP | 有风控 |

- **今日实时**：查询上证综指+深证综指的总市值字段（腾讯源不含北交所；东财兜底时才含北证50，口径差异<1%）
- **历史推算**：锚点插值法——16个历史真实市值锚点（2005~2026，交易所官方统计）之间用**沪深双指数合成**插值（上证/深证综指各自归一化后取几何平均，修正单指数结构偏差），比纯指数缩放准确得多；结果超出相邻锚点合理范围（0.5×min~1.8×max）自动降级为指数缩放，仍异常则拒绝写入（宁缺毋滥）

### GDP

| 优先级 | 源 | 说明 |
|--------|-----|------|
| 1 | 本地缓存（24h） | 命中则直接返回；基线版本号变化即失效 |
| 2 | 硬编码基线 | 2000~2024年官方GDP（2006年起由东财接口覆盖） |
| 3 | 东方财富 `RPT_ECONOMY_GDP` | 2006Q1 至今的年度+季度GDP（累计值，代码内拆单季），第五次经济普查修订口径 |

- GDP每年更新4次，变化不频繁，硬编码基线为主
- 版本号管理：基线数据变更后缓存自动失效（`_GDP_BASELINE["_version"]`）
- 国家统计局 `data.stats.gov.cn` 的 easyquery 接口已不可用（`/easyquery.htm` 返回 403、`/easyquery/api` 返回 404），已从代码中移除

### 反封措施

| 措施 | 实现 |
|------|------|
| UA轮换 | 5个真实浏览器UA，每次请求随机切换 |
| 域名限流 | 腾讯0.3s，东财2.0s |
| 指数退避 | 失败后 1s → 2s → 4s 递增等待 |
| 熔断器 | 同一域名连续2次失败后暂停120s |
| 优先不封IP源 | 腾讯优先于东财 |

## 新增指标

在 `indicators/` 目录下新建 `.py` 文件，继承 `BaseIndicator` 即可自动发现。

```python
from core.base_indicator import BaseIndicator

class MyIndicator(BaseIndicator):
    @property
    def name(self) -> str:
        return "我的指标"        # → 输出 output/我的指标.xlsx

    @property
    def columns(self) -> list[str]:
        return ["日期", "数值A", "数值B", "备注"]

    def compute(self, target_date):
        # 计算逻辑...
        return {
            "日期": target_date,
            "数值A": 100.0,
            "数值B": 200.0,
            "备注": "",
        }
```

无需修改任何配置，`python main.py` 会自动发现并运行（若定义 `value_col`/`html_filename` 属性，自动生成对应HTML页面）。

## CLI 命令

```bash
# 运行所有指标（今天），自动回填缺失交易日 + 更新Excel + 同步HTML
python main.py

# 运行指定日期
python main.py --date 2024-12-31

# 从指定日期起补全所有缺失交易日（如历史半月采样间的空隙）
python main.py --backfill-start 2026-08-01

# 只跑某个指标
python main.py --indicator buffett_indicator

# 查看所有可用指标
python main.py --list

# 静默模式
python main.py --quiet

# 仅重新生成HTML（不调API、不改Excel）
python main.py --html-only

# 计算但跳过HTML生成
python main.py --no-html

# 用当前GDP数据重算全部历史行（分母口径修正后刷新，不请求市值）
python main.py --recompute-gdp
```
