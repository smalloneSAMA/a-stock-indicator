## 指标概述

**巴菲特指标**（又称证券化率）是巴菲特在《Fortune》杂志2001年文章中提出的估值指标：

```
证券化率 = 全市场股票总市值 / 国民生产总值(GDP)
```

| 区间 | 含义 |
|------|------|
| < 60% | 显著低估（历史级底部区域） |
| 60% ~ 75% | 低估区 |
| 75% ~ 90% | 合理区间（当前约78%） |
| 90% ~ 110% | 偏高 → 顶部预警（对标真实历史顶：2007≈164%、2015≈110%） |
| > 120% | 极端泡沫区 |

> ⚠️ 历史顶部阈值以**校正后**的真实市值口径为准：2007年6124点约164%、2015年5178点约110%（早期版本因未计入IPO扩容曾显示200~475%的虚高值，已修正）。A股上市公司盈利98%来自国内，分子分母同源，难以达到美股2021年217%的极端值。

### GDP外推规则（point-in-time）

严格按照数据**发布日**（当年1月17日发布上年全年，季后约17天发布季度数据）回溯当时可得的GDP：

1. 当年已发布季度GDP → 线性外推：(Q1+Q2+Q3)/3×4，或 (Q1+Q2)×2，或 Q1×4
2. 上年全年GDP（当年1月17日后）
3. 上年已发布季度外推
4. 更早年份全年GDP

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行（计算今天并追加到Excel）
python main.py

# 3. 指定日期
python main.py --date 2024-12-31

# 4. 查看所有指标
python main.py --list
```

输出文件：`output/A股证券化率.xlsx`

### 每日使用

```bash
# Windows 定时任务 / 手动运行

# 日志输出示例：
# 2026-07-25 | 总市值=105.93万亿 | GDP=141.00万亿(无2026数据，使用2025年全年GDP) | 证券化率=75.13%
```

已有数据的日期会自动跳过，不会重复请求API。

### HTML 可视化

每次运行后会自动同步生成 `output/证券化率.html`（ECharts 交互式图表，双页面）：

**📈 图表页**：

- **可视范围选择器**：顶部卡片直接选择起止日期（修改即生效/点应用），快捷按钮（近1/3/5/10年、全部），**两图缩放双向联动**（滑块拖拽、日期选择任一操作都会同步到另一页面）
- **拖拽缩放**：底部滑块拖拽选择时间范围（滚轮缩放已禁用）
- **动态趋势线**：虚线为当前可视范围内的线性回归趋势，范围变化自动重算
- **总市值叠加**：点击图例「总市值(万亿)」叠加显示市值曲线（右侧橙色坐标轴）
- **估值参考区（动态·对数正态）**：对可视范围内数据取对数求均值μ±1σ，映射回原尺度划分——底部参考区(绿)、合理区(蓝，约覆盖中间68%)、顶部参考区(红)，随所选时间范围动态计算（乘除对称，适应右偏分布，不受极端值污染）
- **牛熊信号区间**：点击图例「牛熊信号区间」显示/隐藏——X轴方向标出历史牛熊信号区段（绿=熊市底部信号区、红=牛市顶部信号区），基于全历史逐点5项信号打分（≥4/5触发）合并生成；图表页与分析页**各自独立**开关（互不影响），默认隐藏
- **范围统计**：顶部实时显示可视范围的最值

**📊 分析页**（右上角切换）：

- **状态卡**：当前证券化率、历史分位、常规顶部区、常规底部区
- **分析图表**：与图表页**完全相同**（动态估值三区、拖拽缩放、趋势线、市值叠加、牛熊标记），仅额外叠加预测**虚线**——常规顶部区边界(红虚线 76%/110%)、常规底部区边界(绿虚线 35%/69%)、极端顶参考(点线 164%)，不画色带不叠加
- **牛熊预测**（自动检测，不依赖人工标注）：
  - Zigzag算法扫描全部数据点，波动>15个百分点才确认转折，自动识别16个大周期峰谷（8峰/8谷）
  - 常规顶部区 = 峰分布P30~P70分位（91~108%，中位97%）；常规底部区 = 谷分布P30~P70分位（40~60%，中位54%）
  - 极端参考线：峰最大值164%（2007年泡沫）、谷最小值20%（2005年998大底）
  - 时间外推：近12个月趋势斜率，假设趋势延续
  - 回撤参考：峰→谷平均跌幅、熊市周期平均时长
- **预测逻辑说明**：完整解释Zigzag检测、分位区间、极端值处理、外推方法、局限
- **图形解读**：证券化率、区域、趋势线、标记的完整说明
- **🔔 牛熊信号检测**（替代决策参考）：以选定日期为基准，10年/5年/3年三窗口检查——估值位置（绝对锚点62%/90%+窗口分位）、短周期惯性（3年斜率方向）、中周期衰竭（5年走平/涨速衰减），5项条件打分给出强/弱/无信号。历史验证：2024-02底5/5、2015-06顶5/5触发，2016-01熔断低点、2024-10脉冲顶正确排除

## 项目架构

```
a-stock-indicator/
├── main.py                    # 入口：自动发现指标、CLI
├── core/                      # 基础设施（共享）
│   ├── cache.py               # JSON缓存 + TTL过期
│   ├── data_fetcher.py        # HTTP请求（重试+退避+UA轮换+限流+熔断）
│   ├── base_indicator.py      # 指标基类（继承即自动注册）
│   └── excel_writer.py        # Excel追加/更新
├── indicators/                # 指标实现（自动发现）
│   └── buffett_indicator.py   # 证券化率
├── data_sources/              # 数据源（各指标共享）
│   ├── market_cap.py          # A股总市值
│   └── gdp.py                 # 中国GDP
├── output/                    # 输出目录
│   └── A股证券化率.xlsx       # 计算结果
└── requirements.txt
```

### 核心设计原则

- **自动发现**：放在 `indicators/` 目录下、继承 `BaseIndicator` 的类自动被发现
- **多级降级**：每个数据源有2~3层备用源，主源被封自动切换
- **请求限流**：按域名独立限流，腾讯0.3s、东财2.0s间隔
- **熔断保护**：连续2次连接失败后该域名熔断120秒
- **本地缓存**：GDP数据24h缓存，K线数据进程内缓存
- **幂等写入**：同一日期的数据重复运行只更新不重复

## 数据源 & 反封策略

### A股总市值

| 优先级 | 源 | 协议 | 封IP风险 |
|--------|-----|------|---------|
| 1 | 腾讯财经 `qt.gtimg.cn` | HTTP | **不封IP** ✅ |
| 2 | 东财 push2 API | HTTP | 有风控 |

- **今日实时**：直接查询上证综指+深证综指+北证50的总市值字段
- **历史推算**：通过腾讯K线接口获取历史指数点位，按比例缩放各交易所市值

### GDP

| 优先级 | 源 | 说明 |
|--------|-----|------|
| 1 | 硬编码基线 | 2005~2025年官方GDP数据 |
| 2 | NBS easyquery API | 国家统计局公开接口（自动刷新） |

- GDP每年更新4次，变化不频繁，硬编码基线为主
- 版本号管理：基线数据变更后缓存自动失效

### 反封措施

| 措施 | 实现 |
|------|------|
| UA轮换 | 5个真实浏览器UA，每次请求随机切换 |
| 域名限流 | 腾讯0.3s，东财2.0s |
| 指数退避 | 失败后 1s → 2s → 4s 递增等待 |
| 熔断器 | 同一域名连续2次失败后暂停120s |
| 优先不封IP源 | 腾讯优先于东财 |

## 新增指标

在 `indicators/` 目录下新建 `.py` 文件，继承 `BaseIndicator` 即可自动发现。

```python
from core.base_indicator import BaseIndicator

class MyIndicator(BaseIndicator):
    @property
    def name(self) -> str:
        return "我的指标"        # → 输出 output/我的指标.xlsx

    @property
    def columns(self) -> list[str]:
        return ["日期", "数值A", "数值B", "备注"]

    def compute(self, target_date):
        # 计算逻辑...
        return {
            "日期": target_date,
            "数值A": 100.0,
            "数值B": 200.0,
            "备注": "",
        }
```

无需修改任何配置，`python main.py` 会自动发现并运行。
